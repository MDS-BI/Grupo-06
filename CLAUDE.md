# Reglas del proyecto

## Idioma
- Responde siempre en español.
- Escribe todos los archivos (código, comentarios, documentación, especificaciones) en español.

## Git
- Trabaja siempre en la rama `main`.
- **NUNCA** crees ramas nuevas, aunque los scripts de speckit lo intenten. Si un script de speckit intenta crear o cambiar de rama, omite ese paso y continúa en `main`.
- **NUNCA** hagas `git commit` ni `git push`. El usuario realiza los commits y pushes desde GitHub Desktop.

## Speckit
- No modifiques la constitución (`.specify/memory/constitution.md`) ni los templates de `.specify/` salvo que el usuario lo pida explícitamente.
